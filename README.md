# 📄 Basic RAG PDF Chatbot

A simple **Retrieval-Augmented Generation (RAG)** project that allows users to ask questions about a PDF document.

The project extracts text from a PDF, creates embeddings, stores them in a vector database, retrieves relevant information, and uses **Google Gemini** to generate the final answer.

---

## 🚀 Project Overview

This project demonstrates the basic working of a RAG system.

Instead of directly asking an AI model a question, the system first searches the provided PDF for relevant information.
